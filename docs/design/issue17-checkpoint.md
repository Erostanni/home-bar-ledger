## 5. 本轮的用户原始需求（存档，别改需求）

- **酒柜页**：要有「真实的感觉」，网格化，原木感，带一点**每个柜子的顶光**、**文字阴影**等细节。
- **调制页**：参考 **bar us 等顶级酒吧的酒单风格**。左栏希望有**真实酒单的感觉**；
  右侧希望**美化字体、排版**，尽量让**酒名、原料、做法**产生区别。

技术前提（已核实）：CSS 里的 `--serif` 声明了 `Playfair Display` 但**没有实际加载**，
真正生效的是系统衬线（宋体 / Songti SC / Georgia）。所以「酒单感」只能靠
**字重 / 字号 / 字距 / 行高 / 细分隔线 / 留白 / 颜色层级**做，不是换字体。
