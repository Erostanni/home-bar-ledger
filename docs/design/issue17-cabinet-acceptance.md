## 4. 遗留问题

| 编号 | 级别 | 现象 | 复现步骤 | 期望值 |
|---|---|---|---|---|
| **D1** | 低（代码缺陷，视觉无影响） | `background-size` 声明**非法被丢弃**：`background-size:100% 100%, var(--wood-grain-tile) var(--wood-grain-tile), 100% 100%` 中 `var(--wood-grain-tile)` 展开为 `96px 96px`，整条声明变成 4 个值（`100% 100%, 96px 96px 96px 96px, 100% 100%`）→ 非法 | Chrome 打开 `index.html` → 酒柜 → 任一 `.stockcard` → `getComputedStyle(card).backgroundSize` | 第 2 层为 `96px 96px`（当前实测 `auto, auto, auto`）。**当前视觉仍达标**——因 SVG 自身固有尺寸恰为 96×96，被 `background-repeat` 平铺，等效；但该 token 实际未生效，属易碎死代码。修法：写成 `background-size:100% 100%, 96px 96px, 100% 100%`（或把 token 改为单值 `96px`） |
| **D2** | 低 | 无中文名的卡片（`.nm .en.lead`）在移动端主名字号为 **13px**，低于规范的 ≥13.5px | 375×812 触摸模式 → 酒柜 → 找没有中文名的卡片（如 `Aperol Bitter`）→ 量 `.nm .en.lead` 的 font-size | ≥13.5px（有中文名的卡片已是 13.5px，只有 `.en.lead` 漏了） |
| **D3** | 低（视觉偏差） | 浅色主题木色比规范 T1 更深更饱和：实现新增了 `--wood-top:#f7ecd4 / --wood-mid:#e6d2ac / --wood-bot:#b68d5c` 三档，规范 T1 只给了 `--wood-face:#e7d9c0 / --wood-face-2:#d9c6a5` | 切浅色主题看酒柜卡面 | 色值应更接近规范；当前实现的明暗层次更强、可读性没问题，但与规范色值不一致 |
| **D4** | 提示（不违规） | 移动端 `.stocklist` 用 `minmax(240px,1fr)`，规范 §3.2 写的是 `minmax(150px,1fr)`（预期双列） | 375px 视口 | 375px 下实际**单列**；验收第 9 条写「单列或双列」，故判达标，仅提示与规范 §3.2 数值不同 |
| **D5** | 提示（写法差异，不判 FAIL） | 规范 §3.3 规定顶光用 `.stockcard::after` 伪元素，实现改为**把顶光与搁板阴影烤进卡面背景渐变**（`radial-gradient` 光锥 + 三档 `linear-gradient`） | 读 `build/app.template.html` 的 `.stockcard` 规则 | 视觉效果等价且省掉 262 张卡的额外内阴影层（性能考虑），验收第 2/3 条按**视觉**判达标；如需与规范字面一致，需改回 `::after` |

> 另：浅色主题下进度条轨道（`#cbb694`）与浅棕木面对比偏弱（深色主题明显），可考虑加深一档；不影响验收判定。
